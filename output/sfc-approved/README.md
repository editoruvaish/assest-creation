# SFC "granted / Approved" frame – 4K PNG + layered SVG

- `frame-transparent.svg` / `frame-transparent_4K.png` – poora frame, transparent background (2158×3840)
- `frame-on-black_4K.png` – same frame black par (preview)
- `compare_reference-vs-result.png` – reference | result
- `assets/` – har asset alag SVG + 4K PNG (full-frame canvas, position same rehti hai, seedha stack kar sakte ho)
- `assets-cropped/` – same assets tight crop mein (4K scale)

Assets: granted, SFC (+ letter-S/F/C), approved, no-sign (ring + slash), roof, cornice, architrave,
column-1/2/3, base-block, step, plinth, building (sab building pieces), reflection.

Notes
- Text Montserrat outlines mein convert hai (font install nahi chahiye). Reference ka F alag tha, isliye F ka beech wala bar adjust kiya.
- Building ke glossy/mint shading aur slash ka glass tint reference se fit karke har piece mein bake hai (gradient bands). Isliye pieces dark background ke liye bane hain; white background par safed hisse gayab dikhenge.
- Roof aur reflection alpha-mask se bane hain (right side transparent mein fade hoti hai).
- PNG Chromium se render hue (SVG blur/mask filters ke saath). `source/` mein build scripts.
